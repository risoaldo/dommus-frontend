# Dommus - Plataforma de Imóveis e Hospedagens

Plataforma B2B conectando corretores, imobiliárias e hospedagens em Icó/CE.

## 🚀 Rodar o projeto

```bash
# Instalar (escolha um)
npm install
# ou
pnpm install

# Desenvolvimento
npm run dev
# ou  
pnpm dev

# Build
npm run build
```

## 📱 Funcionalidades

- ✅ Listagem de imóveis e hospedagens
- ✅ Filtros dinâmicos por bairro
- ✅ Cards informativos com ícones
- ✅ Suporte MCMV (Minha Casa Minha Vida)
- ✅ Integração WhatsApp
- ✅ Autenticação com LocalStorage
- ✅ Dashboard do anunciante
- ✅ Mobile-first responsivo

## 🎨 Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router
- Lucide Icons
